Fast Terminal X

What is Ftermx?

Browser-based terminal with direct shell access, multi-session, SSH connect, file manager, and public tunnel support.

Auth & Roles

Login-protected with role-based access. Each user gets their own workspace at /ftermx/<username>.

File Manager

Upload, create, delete, extract zip/tar archives, multi-select, and manage files directly in the browser.

Tunneling

Expose publicly via ngrok — secure HTTPS tunnel via pure Node.js, no system tools needed.

Tech Stack

Node.js Express Socket.IO node-pty xterm.js SSH2 @ngrok/ngrok
